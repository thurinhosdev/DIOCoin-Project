# DIO Coin - ERC20 Token Implementation

## 📌 Sobre o Projeto

Projeto desenvolvido durante o Bootcamp Binance Blockchain da DIO.

Este contrato implementa o padrão ERC20 em Solidity, aplicando conceitos fundamentais de blockchain Ethereum como controle de saldo, sistema de allowance e emissão de eventos.

---

## 🚀 Funcionalidades

- Implementação da interface IERC20
- Controle de saldo por endereço
- Transferência de tokens
- Sistema de aprovação (approve / allowance)
- Transferência autorizada (transferFrom)
- Emissão de eventos (Transfer e Approval)
- Validações de segurança básicas

---

## 🛠 Tecnologias Utilizadas

- Solidity ^0.8.0
- Ethereum Virtual Machine (EVM)
- Git e GitHub

---

## 📖 Conceitos Aplicados

- Interfaces em Solidity
- Mappings
- Eventos
- Controle de supply
- Segurança em Smart Contracts
- Versionamento com Git
